=======================================
Foodie AI - Food Recommendation System
=======================================

This is a modern Flask-based web application that filters and recommends food based on your dietary restrictions and calorie limits.

--- PREREQUISITES ---
Make sure you have Python installed on your system.
You will also need the Flask library. If you haven't installed it yet, run:

    pip install flask

--- HOW TO RUN ---

STEP 1: Initialize the Database (Only needed once or if you change the sample data)
Open your terminal/command prompt, navigate to this folder, and run:
    
    python setup_db.py

This will create a 'food.db' file and populate it with sample recipes.

STEP 2: Start the Web Server
Run the Flask application by executing:

    python app.py

You will see output indicating that the server is running on http://127.0.0.1:5000/

STEP 3: Open the App
Open your web browser (Chrome, Edge, Safari, etc.) and go to:

    http://127.0.0.1:5000/

Enjoy your personalized food recommendations!
